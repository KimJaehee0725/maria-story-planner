# Agent Handoff

Date: 2026-05-03

## Current Task

Implemented the timeline mode behavior described in the prior plan. The timeline now has three distinct board-style modes instead of only active segment buttons:

- `이야기 순서`: groups event cards into `과거`, `Act 1`, `Act 2`, `Act 3` columns.
- `회차 기준`: groups event cards by active episodes from `state.data.episodes`, with a final `미배정` column for events not linked to any episode.
- `심리선`: creates lanes only for characters actually connected to the filtered events, shows unassigned events in `미배정`, and emphasizes each event's `emotion`.

  - Psych mode uses active characters linked to current filtered events and includes an emotion variant for `EventCard`.
- Extended `styles.css` with board, column, lane, phase-chip, and psych-card styles.
- Extended `tests/e2e/app-smoke.spec.ts` to verify:
  - default story columns render,

  - psych lanes and emotion text render,
  - `Act 1` phase filter toggles on/off,
  - `관계 미연결만` filters events after relation edits.
